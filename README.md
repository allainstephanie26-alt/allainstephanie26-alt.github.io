# Red Ball Pizza Website Survey

This project is my very first GitHub repository, featuring a simple yet meaningful website survey created for **Red Ball Pizza**. The goal of the survey is to gather customer feedback through an interactive web form while also showcasing my foundational skills in web development and version control.

## Features
- Customer feedback survey form
- Fields: Name, Email, Ratings, and Suggestions
- User-friendly with checkboxes, radio buttons, and text areas
- Built with HTML & CSS

## Purpose
This project serves as part of my Git/GitHub learning journey, applying version control and repository management. It also supports my portfolio building for future courses and internships.
